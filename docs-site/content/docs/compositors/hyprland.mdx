<Callout type="warn" title="Explicit opt-in">

The Hyprland greeter requires Hyprland 0.55 or newer. It uses `start-hyprland` and the Lua config. The installer shows it only when you set `SYSC_COMPOSITOR=hyprland`.

Check startup, login, and quit on the target machine before enabling greetd.

</Callout>

## Installer

From a source checkout, expose the Hyprland option with:

```bash
SYSC_COMPOSITOR=hyprland go run ./cmd/installer/
```

The `sysc-greet-hyprland` AUR package also selects this backend. Install Hyprland 0.55 or newer first when using another package format.

## greetd Command

The greeter config lives at `/etc/greetd/hyprland-greeter-config.lua`. Set both greetd session commands to:

```toml
[default_session]
command = "start-hyprland -- --config /etc/greetd/hyprland-greeter-config.lua"
user = "greeter"
```

The installer and package use this command. After changing greetd configuration, reboot to activate it.

## Lua Config

The repository ships `config/hyprland-greeter-config.lua`. It disables animations and decorations, starts the wallpaper daemon, and launches fullscreen Kitty with sysc-greet. After Kitty exits, the config asks Hyprland to quit so greetd can continue with the user session.

Run `luac -p config/hyprland-greeter-config.lua` to check Lua syntax. This check does not verify compositor startup, authentication, or quit behavior. Those checks still need a physical Hyprland test.
